# Dati pubblicati

Questo ramo è scritto in automatico a ogni pubblicazione dell'app (flusso «Pubblica»).
Contiene i file di dati così come sono online in quel momento (sul sito stanno sotto `data/`):
l'elenco dei prodotti sigillati con i prezzi di Cardmarket e i rapporti che dicono quanto è completo.
Ha sempre un solo commit, che viene sostituito: non va modificato a mano.
